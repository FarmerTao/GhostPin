## 需求与证据

用户希望实体 iPhone 向微信小程序“复旦学生注册”报告复旦大学附近的位置，随后明确是**邯郸校区**。Agent 选取光华楼附近作为地标；用户使用后要求恢复。

这是可复用的**设备操作案例**，不是注册成功或小程序接受模拟定位的证明。定位 skill 不应点击或提交注册。

| 项目 | 记录的观察 |
|---|---|
| 电脑 | macOS 15.4 |
| 运行时 | Python 3.12.14；pymobiledevice3 11.19.4 |
| 手机系统 | 设备查询返回 26.6.1 |
| 开发者模式 | 初始 false；reveal 成功；用户操作后查询返回 true |
| 支持镜像 | 首次挂载因 `DeviceLocked` 失败；用户解锁后成功 |
| 模拟定位 | 原生隧道回退后，set 命令进入持续等待状态 |
| 地图验证 | 未记录 |
| 小程序接受情况 | 未记录 |
| 恢复 | 中断 set 会话，显式 clear 命令以 0 退出 |
| 恢复后的地图验证 | 未记录 |

这些证据来自原始会话直接执行的上游命令。新仓库封装脚本通过模拟响应测试，没有为了发布仓库而再次操作手机。

## 坐标来源

来源：[高德地图，复旦大学邯郸校区光华楼](https://ditu.amap.com/place/B00155K7SX)，查询日期 2026-09-28。地图坐标按 GCJ-02 处理：

| 坐标系 | 纬度 | 经度 |
|---|---|---|
| 来源 GCJ-02 | 31.300023 | 121.505283 |
| 近似转换 WGS84 | 31.3020138 | 121.5008487 |

这是地标坐标，不是官方注册围栏或保证有效的签到点。应在地图上检查实际位置；小数位数不代表厘米级精度。

离线转换，不访问手机：

```bash
python3 skills/ghostpin/scripts/coordinates.py \
  --lat 31.300023 --lon 121.505283 --source gcj02
```

完成连接、开发者模式和支持文件准备后，在持续运行的终端执行：

```bash
skills/ghostpin/.venv/bin/python skills/ghostpin/scripts/location.py \
  set --udid YOUR_DEVICE_ID --lat 31.300023 --lon 121.505283 --source gcj02
```

Helper 只转换一次。如果直接输入已转换的 WGS84 数值，必须使用 `--source wgs84`，不要二次转换。保持会话，用户分别验证地图和小程序；完成后在 helper 中 Ctrl+C，或按需运行 `clear --udid YOUR_DEVICE_ID`，再次检查当前位置。

## 可复用经验

- 先明确校区，随后保留用户答案。
- 插上线还不够，需要信任、开发者模式，以及挂载时保持解锁。
- 入口隐藏时可请求 reveal，用户完成手机上的开启流程。
- 隧道回退警告不等于最终失败。
- Raw GitHub 不通时可尝试官方 API；校验内容，不把镜像提交到 Git。
- 区分命令、地图和应用三层结果。
- 显式清除模拟定位，不依赖拔线恢复。
